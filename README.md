# Academic Research

Personal academic research repository.

The ARS-Codex research skill suite is maintained upstream at [Imbad0202/academic-research-skills-codex](https://github.com/Imbad0202/academic-research-skills-codex). Any proposed integration is reviewed through a pull request before merging into `main`.

## Norman Skills

All five Norman Skills are included through a pinned submodule at `.agents/skills`. See [setup, skill inventory, and platform requirements](docs/norman-skills.md). Clone with `--recurse-submodules`, or run `git submodule update --init --recursive` after pulling.
